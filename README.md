# Virtual laboratoriya platformasi

Diplom loyiha mavzusi asosida tayyorlangan GitHub Pages uchun statik platforma.

## Kirish ma'lumotlari

- Admin: `admin` / `admin123`
- O'qituvchi: `teacher1` / `teacher123` ... `teacher30` / `teacher123`
- Talaba: `student1` / `student123` ... `student30` / `student123`

## Tarkibi

- 30 ta talaba
- 30 ta o'qituvchi
- 30 ta fan
- Har fan uchun 3 ta laboratoriya ko'rsatkichi
- Test bo'limida 30 ta savol
- Admin, o'qituvchi va talaba panellari
- Virtual tajriba: Om qonuni asosida hisoblash, jadval va canvas grafik
- Natijalar, hisobotlar va monitoring modullari

## GitHub Pagesga joylash

1. GitHubda yangi repository oching.
2. `index.html`, `style.css`, `app.js`, `README.md` fayllarini yuklang.
3. Repository `Settings` → `Pages` bo'limiga kiring.
4. `Deploy from a branch` tanlang.
5. Branch: `main`, Folder: `/root` ni tanlang.
6. `Save` bosing va chiqqan havolani oching.

## Eslatma

Bu loyiha backend talab qilmaydi, barcha ma'lumotlar browser `localStorage`ida saqlanadi. Shuning uchun GitHub Pagesda muammosiz ishlaydi.
